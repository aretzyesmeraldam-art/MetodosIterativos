# Práctica: Métodos Iterativos (Jacobi y Gauss-Seidel) en Java

Este repositorio contiene la implementación en Java de una arquitectura modular de tres componentes para resolver sistemas de ecuaciones lineales mediante los métodos de Jacobi y Gauss-Seidel.

## Estructura del Proyecto
- `SistemaEcuaciones.java`: Contiene la matriz de coeficientes, vector independiente, vector inicial y tolerancia.
- `MetodosIterativos.java`: Implementación de los algoritmos numéricos.
- `Main.java`: Clase principal que ejecuta ambos métodos.
